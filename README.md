# 群聊日报插件 (astrbot_plugin_daily_summary)

基于日志文件，统计当日发言排行，并可选调用LLM生成趣味总结。支持手动触发指令和每日定时自动推送。

> **声明**：本插件的核心代码由 DeepSeek（AI）辅助生成，经人工调试与整理，仅供学习交流使用。

## ✨ 功能

- 📊 统计当日发言排行榜（纯文本）
- 🤖 调用LLM生成幽默总结
- 🎯 支持 `/daily summary` 和 `/daily stats` 两种模式
- ⏰ 支持每日定时自动推送（可配置时间和目标群）
- 📁 直接读取日志插件生成的日志文件

## 📦 安装

1. 将本插件放入 `data/plugins/` 目录。
2. 确认已安装 `apscheduler`（本插件自带 `requirements.txt`，AstrBot 会自动安装）。
3. 在 WebUI 中重载插件。
4. 配置日志目录（与你之前安装的日志插件保持一致）。

## ⚙️ 配置选项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `log_dir` | string | 日志文件目录（必填，需与日志插件路径一致） |
| `filter_self` | bool | `true` | 是否过滤机器人自身消息 |
| `bot_qq` | string | `""` | 机器人的QQ号（用于过滤自身消息，留空则不过滤） |
| `enable_schedule` | bool | `true` | 是否启用定时推送日报 |
| `schedule_time` | string | `08:00` | 定时推送日报的时间（HH:MM 格式） |
| `target_groups` | list | `[]` | 定时推送日报的目标群号 |
| `use_llm_in_schedule` | bool | `true` | 定时推送是否包含LLM总结 |

## 🚀 使用方法

在群聊中发送：
- `/daily summary` - 生成今日发言排行 + AI总结
- `/daily stats`   - 仅统计今日发言排行
- `/daily help`    - 显示帮助信息

### ⏰ 定时推送
插件会根据 `schedule_time` 和 `target_groups` 的配置，每天自动推送到指定群聊。

## 📝 示例输出

```text
📊 今日发言排行（2026-02-19）：

1.张三 (1234567890)：42条
2.李四 (1145141919)：28条
3.你 (123123123)：15条

📈 今日总消息数：85条

🧠 AI总结：
今天张三同学继续霸榜，分享了不少OC新想法！群里气氛不错～

```

## 📌 注意事项
- **前置依赖**：本插件依赖你之前安装的**日志插件**生成的日志文件。
- 日志文件名格式必须为 `YYYY-MM-DD_群ID.log`。
- 调用LLM需要AstrBot已配置好提供商（如DeepSeek）。
- 定时推送依赖 `APScheduler` 库，已写入 `requirements.txt`。
